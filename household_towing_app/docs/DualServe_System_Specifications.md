## 1. Hardware and Software Requirements
These specifications define the minimum and recommended environments to ensure the DualServe system operates smoothly and efficiently.

### 1.1 Recommended Minimum Hardware Requirements
*   **Device:** Android 6.0+ smartphone / Desktop or laptop
*   **Processor:** Dual-core 1.5 GHz or higher
*   **RAM:** At least 4 GB of RAM for smooth system operation and map rendering
*   **Storage:** 250 MB free (for app installation and PWA cache)
*   **Screen Resolution:** 360 × 640 pixels (Mobile); 1366 x 768 (Desktop)
*   **Location Services:** GPS-enabled device (Mandatory for real-time tracking)
*   **Camera:** 8 MP or better (Required for capturing vehicle/incident photos)
*   **Internet:** Stable 4G/5G or Wi-Fi connection for real-time data synchronization.

### 1.2 Recommended Software Requirements
*   **Operating System:** Android 6.0 (Marshmallow) or higher, Windows 10+, or modern Linux distributions.
*   **Browser (for Web/PWA version):** Google Chrome 90+, Mozilla Firefox 88+, or Microsoft Edge 90+
*   **Browser Features:** Must support WebGL, Service Workers, IndexedDB, Geolocation API, and Web Manifest.
*   **Internet Browser Mode:** Up-to-date version (auto-updates recommended).
*   **Additional Permissions:** 
    *   **Location:** Always / While Using
    *   **Camera:** For profile and incident photo uploads
    *   **Notifications:** For real-time booking alerts
*   **PWA Installation:** Recommended: “Add to Home Screen” for offline incident drafting and faster access.

## 2. Data Dictionary
The following tables define the structure and purpose of the core data entities stored in the DualServe Firebase database.

### 2.1 Users Collection (`users`)
| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `uid` | String (ID) | Unique identifier for the user (from Firebase Auth). |
| `name` | String | Full name of the user. |
| `email` | String | Primary email address. |
| `phone` | String | Contact number. |
| `role` | String | User role: `customer`, `provider`, `admin`, `pending_provider`. |
| `createdAt` | Timestamp | Date and time the account was created. |

### 2.2 Providers Collection (`providers`)
| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `id` | String (ID) | UID of the provider (matches the `users` ID). |
| `specialty` | String | Primary skill (e.g., "Heavy Duty Towing"). |
| `rating` | Double | Average star rating (1.0 - 5.0). |
| `isAvailable` | Boolean | Toggle for whether the provider can take new jobs. |
| `weeklySchedule` | Map | Operating hours (Day -> TimeSlots). |

### 2.3 Bookings Collection (`bookings`)
| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `id` | String (ID) | Unique identifier for the booking. |
| `customerId` | String (Ref) | UID of the customer who made the booking. |
| `serviceType` | String | Type of service requested (`Towing` or `Household`). |
| `status` | String | `pending`, `accepted`, `rejected`, `converted_to_task`, `cancelled`. |
| `estimatedCost` | Double | The calculated price shown to the customer. |

### 2.4 Tasks Collection (`tasks`)
| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `id` | String (ID) | Unique identifier for the task. |
| `status` | String | `assigned`, `inProgress`, `completed`, `cancelled`. |
| `location` | String | Service location address. |
| `latitude` / `longitude` | Double | Geolocation coordinates for map tracking. |
| `completedAt` | Timestamp | Final timestamp when the job was finished. |

### 2.5 Assets Collection (`assets`)
| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `id` | String (ID) | Unique identifier for the asset. |
| `category` | String | Classification (e.g., "Tow Truck", "Toolkit"). |
| `type` | String | `vehicle`, `tool`, or `equipment`. |
| `status` | String | `active`, `maintenance`, `inactive`, `inUse`. |

### 2.6 Transactions Collection (`transactions`)
| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `id` | String (ID) | Unique identifier for the transaction. |
| `finalCost` | Double | Final price charged to the customer. |
| `paymentStatus` | String | `pending` or `recorded`. |
| `completedAt` | Timestamp | Time the transaction was finalized. |

### 2.7 Messages Collection (`messages`)
| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `bookingId` | String (Ref) | Link to the specific job context. |
| `senderId` | String (Ref) | UID of the message sender. |
| `text` | String | Content of the message. |
| `timestamp` | Timestamp | Date and time sent. |
